# 数感 · 高中数学全五册

从简单例子开始，先看懂，再一步步做对。

包含人教A版高中数学五册、18章、77个学习单元，398个知识小步、169道分步例题、308道随堂练习、77张图解和14个基础补课主题。每节均可动手实验。

在线版直接在浏览器使用，无需安装。学习记录保存在使用者自己的浏览器中；可导出笔记、备份记录，在另一台设备导入继续。

## 发布

此目录为完整静态网站，可直接由 GitHub Pages 从 main 分支根目录发布；.nojekyll 禁用额外构建。所有资源采用相对路径，支持项目子目录。

KaTeX 许可见 assets/katex/LICENSE。教材正文由项目提供的五册PDF保留，课程讲解、练习与图解按知识点重新编写。
